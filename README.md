# مجلة ورقة - Waraqah Full-Stack

نظام كامل (Backend + Frontend) لإدارة مجلة أدبية إلكترونية: تقديم مقالات، سير عمل مراجعة كامل (نشر/تعديل/حظر)، محادثة بين الكاتب والمراجع، ملفات صوتية، حسابات قرّاء منفصلة مع محتوى حصري وتقييمات، فريق تحرير بصلاحيات، وسجل مراجعات دائم.

## البنية

```
waraqah/
├── server/     ← الباك إند (Node.js + Express + MongoDB)
└── client/     ← الواجهة الأمامية (HTML + Tailwind + JS خالص، بدون أي إطار عمل)
```

## خطوات التشغيل السريع (على جهازك محليًا)

### 1) قاعدة البيانات
أسهل طريقة: أنشئ قاعدة بيانات مجانية على [MongoDB Atlas](https://www.mongodb.com/atlas) واحصل على رابط الاتصال (Connection String).
أو شغّل MongoDB محليًا لو مثبّت عندك.

### 2) الباك إند
```bash
cd server
npm install
cp .env.example .env
# افتح .env واملأ MONGO_URI و JWT_SECRET
npm run dev
```
هيشتغل على `http://localhost:5000`.

### 3) الواجهة الأمامية
افتح `client/config.js` وتأكد إن `API_BASE_URL` بيشاور على `http://localhost:5000/api` (القيمة الافتراضية صحيحة للتجربة المحلية).

بعد كده افتح `client/index.html` مباشرة في المتصفح، أو استخدم أي سيرفر ملفات ثابتة بسيط زي:
```bash
cd client
npx serve .
```

### 4) إنشاء أول حساب (المالك)
من نافذة "دخول الموظفين" في الموقع، دوس على رابط **"لسه مفيش أي حساب؟ أنشئ حساب المالك الأول"** واملأ اسم مستخدم وكلمة سر. هذا الإجراء يعمل مرة واحدة بس.

بعد كده سجّل دخولك كمالك، وهتلاقي قسم "إنشاء حساب جديد للموظفين" ظاهر في الشريط الجانبي — استخدمه لإضافة باقي الفريق (رئيس تحرير، كتّاب، مدققين... إلخ).

## نظام "ورق" - نقاط ولاء القراء (جديد)

نظام مكافآت كامل للقراء المسجلين، محسوب بالكامل من السيرفر (لا يُعتمد على أي رقم قادم من المتصفح):

**طرق الكسب:**
- إنشاء حساب: +100 (مرة واحدة) | تسجيل دخول يومي: +5 | سلسلة قراءة 7 أيام متتالية: +50
- قراءة مقال كامل (120 ثانية فعلية): +5 | وقت نشط: +2/دقيقة (سقف 20 دقيقة/يوم)
- إعجاب: +2 (مرة واحدة لكل مقال) | تعليق: +2 (حد أقصى تعليقين/يوم) | مشاركة: +10 (مرة واحدة لكل مقال) | دعوة صديق: +50

**الحماية من الغش:**
- تتبّع "الوقت النشط" عبر heartbeat كل 20 ثانية، يُقبل فقط لو `document.visibilityState === 'visible'` والمستخدم تفاعل (سكرول/ماوس/كيبورد) خلال آخر 25 ثانية.
- كل حساب النقاط والخصم يتم بالكامل في الباك إند (`utils/pointsEngine.js`) — الفرونت إند لا يرسل أي رقم نقاط جاهز.
- Rate limiting مخصص على مسار الـ heartbeat لمنع الإغراق.

**الرتب** (مبنية على إجمالي الورق المكتسب مدى الحياة، راجع `server/utils/ranks.js`):
العابر (0) ← القارئ المواظب (201) ← المُطالع الشغوف (801) ← الناقد المشارك (5000) ← سادن الحرف (10000) ← عميد الورقة (15000).

**متجر الهدايا**: يديره فريق (المالك/رئيس التحرير/IT) من لوحة "إدارة كتالوج الهدايا" داخل متجر الهدايا نفسه، بأنواع تسليم مختلفة (تلقائي/كود خصم/شحن/دعوة).

## استعادة كلمة السر عبر الإيميل (Gmail SMTP)

القارئ اللي نسي كلمة سره يقدر يطلب رابط إعادة تعيين من تاب "نسيت بياناتي" في نافذة حساب القارئ. عشان الميزة دي تشتغل، لازم تظبط في `server/.env`:
- `GMAIL_USER`: إيميل Gmail هيبعت منه الرسائل
- `GMAIL_APP_PASSWORD`: **مش** كلمة سر الإيميل العادية - لازم "App Password" مخصصة (فعّل التحقق بخطوتين على حسابك في myaccount.google.com/security، وبعدها أنشئ App Password من myaccount.google.com/apppasswords)
- `PASSWORD_RESET_URL`: رابط صفحة `reset-password.html` بعد رفع الموقع (مثلاً `https://waraqah-magazine.com/reset-password.html`)

## العضوية الذهبية والدفع (Paymob)

مقالات "محتوى ذهبي" متاحة بس لأصحاب العضوية الذهبية المدفوعة. الدفع بيتم عبر **Paymob** (بوابة الدفع المصرية اللي بتغطي الفيزا/الماستركارد **و**المحافظ الإلكترونية الأربعة: فودافون كاش، اتصالات كاش، أورانج موني، وي باي).

**خطوات التفعيل:**
1. سجّل حساب على [accept.paymob.com](https://accept.paymob.com)
2. من لوحة تحكمك هناك، فعّل تكاملين (Integrations): واحد للكروت (Card) وواحد للمحافظ (Mobile Wallet)
3. من Developers > Payment Integrations، اجمع القيم دي وحطها في `server/.env`:
   - `PAYMOB_API_KEY` (من Settings > Account Info)
   - `PAYMOB_INTEGRATION_ID_CARD` و `PAYMOB_INTEGRATION_ID_WALLET`
   - `PAYMOB_IFRAME_ID`
   - `PAYMOB_HMAC_SECRET` (من Settings > Account Info، مهم جدًا للتحقق من صحة إشعارات الدفع)
4. من نفس لوحة Paymob، اضبط رابط الـ Webhook على: `https://your-domain.com/api/payment/webhook`
5. عدّل `GOLD_MEMBERSHIP_PRICE_EGP` بالسعر اللي تحدده بالجنيه المصري

آلية العمل: القارئ يدفع (كارت أو محفظة) ← Paymob تبعت إشعار (Webhook) موقّع بـ HMAC للسيرفر ← السيرفر يتحقق من التوقيع ويفعّل `isGoldMember` تلقائيًا. ممكن كمان المالك/رئيس التحرير يمنح أو يسحب العضوية يدويًا من لوحة "إدارة العضوية الذهبية" في أي وقت.

## النشر على Vercel (GitHub + Mongo Atlas)

بما إن المشروع مكوّن من مجلدين منفصلين (`client` و`server`) جوه نفس الـ Repo، لازم تعمل **مشروعين منفصلين على Vercel** من نفس الـ Repo (مش مشروع واحد):

### 1) نشر الباك إند (server)
1. من لوحة Vercel: **Add New Project** → اختر الـ Repo بتاعك على GitHub
2. في إعدادات المشروع، حدّد **Root Directory** = `server`
3. Vercel هيكتشف ملف `vercel.json` الموجود جوه `server/` تلقائيًا (بيحوّل `server.js` لـ Serverless Function)
4. من **Settings > Environment Variables**، ضيف **كل المتغيرات** الموجودة في `server/.env.example` (يدويًا واحد واحد - Vercel معندوش مفهوم رفع ملف `.env` كامل) خصوصًا:
   - `MONGO_URI` (من Mongo Atlas)
   - `JWT_SECRET`
   - `CLIENT_ORIGIN` (هتحطه بعد ما تعرف رابط الفرونت إند من الخطوة التالية)
   - كل متغيرات Cloudinary وGmail وPaymob
   - **`VERCEL`**: Vercel بيحطها تلقائيًا لوحده، مش محتاج تضيفها يدويًا
5. اضغط Deploy، وهتاخد رابط شكله `https://waraqah-api.vercel.app`

### 2) نشر الفرونت إند (client)
1. **Add New Project** تاني من نفس الـ Repo
2. **Root Directory** = `client`
3. مفيش أي إعدادات بناء مطلوبة (Framework Preset: Other) لأنه HTML/CSS/JS خالص
4. **قبل الـ Deploy**: افتح `client/config.js` في الـ Repo وغيّر السطر لرابط الباك إند اللي طلع من الخطوة اللي فاتت:
   ```js
   var API_BASE_URL = 'https://waraqah-api.vercel.app/api';
   ```
5. Deploy، وهتاخد رابط شكله `https://waraqah-magazine.vercel.app`

### 3) اربط الاتنين ببعض
ارجع لمشروع الباك إند على Vercel وحدّث متغير `CLIENT_ORIGIN` بالرابط النهائي للفرونت إند، وأعد النشر (Redeploy) عشان إعدادات CORS تشتغل صح.

### 4) Mongo Atlas: اسمح لـ Vercel بالاتصال
سيرفرات Vercel Serverless معندهاش IP ثابت، فلازم من **Network Access** في Mongo Atlas تضيف `0.0.0.0/0` (السماح من أي مكان) بدل ما تحدد IP معيّن.

### 5) Paymob Webhook
حطّ رابط الباك إند بتاع Vercel في إعدادات الـ Webhook على لوحة Paymob:
```
https://waraqah-api.vercel.app/api/payment/webhook
```

## عند النشر الفعلي (منصات تانية غير Vercel)

1. **الباك إند**: انشره على أي استضافة تدعم Node.js (Render, Railway, DigitalOcean, VPS عادي...). تأكد من ضبط متغيرات البيئة (`MONGO_URI`, `JWT_SECRET`, `CLIENT_ORIGIN`) في لوحة تحكم الاستضافة نفسها، ومتحطش ملف `.env` في أي مكان عام.
2. **رفع الملفات**: بقت متخزنة على Cloudinary مش على القرص المحلي، فمينفعش أي مشكلة حتى لو الاستضافة Serverless أو بتعيد تشغيل الحاوية بشكل دوري.
3. **الواجهة الأمامية**: ارفعها على أي استضافة استاتيك (Netlify, Vercel, GitHub Pages، أو نفس السيرفر). **مهم جدًا**: افتح `client/config.js` وغيّر `API_BASE_URL` لرابط الباك إند الحقيقي بعد نشره.
4. اضبط `CLIENT_ORIGIN` في متغيرات بيئة الباك إند على رابط الواجهة الأمامية الحقيقي، عشان إعدادات CORS تشتغل صح.

## ملاحظة أمنية مهمة

الكود ده تمت كتابته بعناية (تشفير كلمات السر bcrypt، JWT، صلاحيات محكمة حسب الدور، Helmet، Rate Limiting)، لكن **راجعه مع مطوّر Node.js موثوق قبل الاعتماد عليه في بيئة إنتاج حقيقية بها بيانات حقيقية لمستخدمين**، خصوصًا لو هتضيف مميزات جديدة بنفسك لاحقًا.
